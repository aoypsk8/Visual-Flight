# Flight sounds (bundled)

**Live flight** uses only `flight_cruise.mp3`, looping from **0:08** (see `FlightAudioAssets.cruiseLoopStart`).

| File | Used in app | Source (Mixkit License) |
|------|-------------|-------------------------|
| `flight_cruise.mp3` | Live flight loop from 0:08 | [Transport airplane flying rumble](https://mixkit.co/free-sound-effects/airplane/) (ID 1590) |
| `flight_takeoff.mp3` | (optional, not used) | Mixkit #1577 |
| `flight_landing.mp3` | (optional, not used) | Mixkit #1586 |

License: [Mixkit Free License](https://mixkit.co/license/) — free for commercial use in video/audio projects.

## Replace with your own

Drop new MP3s with the same filenames. Run `flutter clean && flutter run`.

## Other free sources

- [Freesound](https://freesound.org/search/?q=airplane+cabin) — check CC0 / CC BY per file
- [Pixabay Sound Effects](https://pixabay.com/sound-effects/search/airplane/)

Do **not** bundle audio ripped from YouTube.
